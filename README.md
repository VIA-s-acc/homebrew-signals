# Homebrew tap for Signals

[Signals](https://github.com/VIA-s-acc/SignalProc) — filter banks, wavelets and Toeplitz matrices with a terminal interface.

```bash
brew install VIA-s-acc/signals/signals
```

The formula installs the prebuilt binaries from the [releases](https://github.com/VIA-s-acc/SignalProc/releases) and is updated automatically on every release. macOS 14 or newer, Linux x86_64.
